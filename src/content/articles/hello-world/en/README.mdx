Welcome to **Personal Site**. This first article exists to prove the article
template works end to end: a long-form reading view with an H1 title, an H3 dek,
a meta line, and body prose — all authored in MDX.

## Importing shared components

Because articles are MDX, they can import and render shared components to vary
their structure. Here is a `Callout`:

<Callout title="Why MDX?">
  MDX lets a single article opt into a richer layout without changing any page
  code. Drop in a component, and it renders inline with the prose.
</Callout>

## Colocated assets

The cover image above lives right next to this file, inside the article's own
folder. Adding a new article is as simple as creating one folder with its
per-locale `README.mdx` files and any assets it needs.

## Progressive enhancement

This page is fully static. It reads perfectly with JavaScript disabled — there
is no client-side hydration required to view the content.
