Astro no envía JavaScript por defecto y genera HTML estático, lo que encaja
perfecto para un blog personal.

## Puntos clave

1. Colecciones de contenido con frontmatter tipado
2. MDX para algún componente interactivo ocasional
3. Enrutamiento i18n de primera clase
