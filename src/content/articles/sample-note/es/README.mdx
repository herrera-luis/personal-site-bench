Las paginas duraderas no necesitan ser ruidosas. Necesitan una direccion clara, texto legible y enlaces que sigan funcionando cuando los scripts no estan disponibles.

<Callout title="Principio de diseno">
  Este articulo se renderiza desde MDX, pero la navegacion, el cambio de idioma y la prosa funcionan como HTML sencillo.
</Callout>

Lo demas es contencion: pocas rutas, metadatos localizados y una carpeta de contenido que hace predecible agregar otro articulo.
