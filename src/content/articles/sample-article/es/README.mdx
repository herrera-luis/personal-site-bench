## Field notes

Este artículo de muestra es intencionalmente breve, pero usa la misma estructura de carpeta por artículo prevista para textos futuros. Los archivos en inglés y español viven juntos bajo una sola carpeta de slug, así que agregar otro artículo solo requiere crear una carpeta nueva con archivos README localizados y sus recursos colocados junto a ellos.

<ArticleCallout title="Prueba de plantilla">
  Este recuadro se importa desde un componente Astro compartido dentro de MDX, demostrando que un artículo puede variar su estructura cuando la escritura lo necesita.
</ArticleCallout>

La página sigue siendo legible como HTML estático. La navegación, el cambio de idioma, los metadatos y los enlaces de feed se renderizan durante la compilación sin depender de JavaScript del cliente.

## Un cierre sobrio

El sistema visual favorece tipografía tranquila, una longitud de línea cómoda y la preferencia de color de cada persona lectora. Los artículos futuros pueden mantener el diseño estándar o elegir una variante más amplia mediante frontmatter.
