# Personal Site

A minimal bilingual Astro + MDX personal website/blog scaffold using placeholder identity only.

## Commands

- `npm install` - install dependencies
- `npm run dev` - start local development
- `npm run build` - build the static site
- `npm test` - verify built routes, i18n links, hreflang, feeds, and sitemap output

The site is static, deployable to Vercel, and uses URL-prefixed English and Spanish routes.
